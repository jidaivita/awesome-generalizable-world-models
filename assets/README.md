# Visual assets

`research-map.svg` is an original, editable vector illustration created for this repository.

- **Represent:** a conceptual latent surface with a trajectory.
- **Generalize:** corresponding relational structures under an environment change.
- **Use:** candidate predicted futures with a highlighted plan.

The three panels denote complementary research questions. They do not depict experimental measurements or the architecture of any listed paper. All shapes are original SVG geometry; no external icons, logos, photographs, or paper figures are included. Text uses the Arial/Helvetica/system sans-serif stack.

The SVG is self-contained, includes an accessible title and description, and has no external asset dependencies.
