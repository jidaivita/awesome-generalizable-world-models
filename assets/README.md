# Visual assets

## Cover illustration

`world-models-cover.png` is an original conceptual cover produced for this repository with OpenAI image generation. Physical scenes connect to shared latent dynamics and an analytical view of representation channels and interventions. The scene is editorial artwork, rather than a diagram of a listed model or a measured result. It contains no figures or logos taken from the linked papers.

The README layout and linked resource badges were informed by [Awesome World Models](https://github.com/knightnemo/Awesome-World-Models). The cover was created independently for this catalog's focus on mechanisms, generalization, and interpretability.

## Earlier vector illustration

`research-map.svg` is an original, editable vector illustration created for this repository.

- **Represent:** a conceptual latent surface with a trajectory.
- **Generalize:** corresponding relational structures under an environment change.
- **Use:** candidate predicted futures with a highlighted plan.

The three panels denote complementary research questions. They do not depict experimental measurements or the architecture of any listed paper. All shapes are original SVG geometry; no external icons, logos, photographs, or paper figures are included. Text uses the Arial/Helvetica/system sans-serif stack.

The SVG is self-contained, includes an accessible title and description, and has no external asset dependencies.
